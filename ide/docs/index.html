JAPPL Documentation

A quick reference for writing Scratch-style programs in JAPPL.

JAPPL compiles to .sb3 projects. Use Compile & Run in the IDE to test your project.

Basics

Statements use Scratch-like syntax. Text literals must be surrounded by double quotes.

when (green flag)
{
    say ("Hello world") for (2) seconds
    move (10) steps
}

An unquoted name is interpreted as an expression, such as a variable. Therefore say (hello) reads the value of the variable hello, while say ("hello") displays the text.

Events

when (green flag) starts a script when the project is run.

when (green flag)
{
    say ("Started!")
}

Motion

Common motion blocks include:

  • move (10) steps
  • turn cw (15) degrees
  • go to x (0) y (0)
  • change x by (10)
  • change y by (10)

Looks

say displays text. Costumes can be selected by name.

say ("Hello!") for (2) seconds
switch costume to (costume1)
next costume

Variables

Variables are expressions when used without quotes. Their value can be changed using the variable blocks supported by JAPPL.

set (score) to (10)
change (score) by (1)
say (score)

Lists

Lists support adding, deleting, replacing and reading items where supported by the current compiler.

add ("apple") to (my list)
add ("banana") to (my list)

Control

Use loops and conditions to control scripts.

repeat (10)
{
    move (10) steps
}
if <score > 10>
{
    say ("High score!")
}

Operators & strings

JAPPL supports Scratch-style arithmetic, comparisons and boolean expressions. Use parentheses for block inputs and quotes for literal strings.

say ((2) + (3))
say ("hello world")
say (score)

Custom blocks

Custom blocks can be declared and called using JAPPL's custom-block syntax supported by the compiler.

Costumes

Add image files through the IDE's Costumes panel. When you compile, the assets are included in the generated SB3.

Compile & Run

  1. Write your JAPPL program in the center editor.
  2. Click Compile & Run.
  3. The generated SB3 is packaged locally and shown in the stage.
  4. Use the green flag and stop buttons to control the project.

Tips

  • Quote literal text: "hello".
  • Use variable names without quotes when you want their value.
  • Compile after changing source or costumes.
  • If compilation fails, check the error panel below the editor.
